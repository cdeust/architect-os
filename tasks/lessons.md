# Engineering lessons

Keep the gateway call flow and the runtime isolation view distinct in the README diagram. Trace each connector to the code, then render both sections together at README width to catch repeated boundaries.

Verify the outcome on the Step path that can publish a change. A structured acceptance or provider completion can precede a native exit failure. Use the process exit, terminal event and timeout status together for build, scout and review.

Test the lifetime of the host credential independently of a sandbox process. Use one consent and two fresh sandbox runs, including a real token rotation. Record whether each native command executed and whether a separately requested model turn delivered an answer.

Draw each runtime where its isolation is enforced. Claude runs as a process under SRT. The native client in Docker SBX runs inside a VM, with the subscription broker on the host. Update the diagram when either boundary changes and qualify the actual client outcome through shutdown.

When a subscription stream ends before the native receipt, record the host error separately from the account owner’s diagnosis. An HTTP 200 alone establishes neither completed inference nor token usage. Keep the monetary cost unknown until a provider receipt or account statement establishes it.

Keep provider accounting available when native admission refuses an event. Observe the already bounded stream independently, bind its terminal to the created response and exact model, and validate the token counts before recording them. Preserve the native refusal. A retained `requires_native_handling` disposition identifies the decision only. Leave the underlying control unknown when the receipt omits its field names.

- A ChatGPT subscription request has its own wire contract. Check the [SIWC preview limits](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations) before using a field from the general Responses API. A local release limit cannot cap tokens generated by the provider.

A provider terminal and its token counts establish inference. Before releasing its answer to SBX, handle each HTTP control in its own scope and preserve actionable stream notifications. A gateway header cannot authorize a moderation report. Bind the native receipt to the fresh challenge so a result with matching token counts from a different turn cannot qualify.

- Pour un constructeur sous abonnement, distinguer l’installation interactive du Step sans intervention. Vérifier une installation suivie d’un Step dans deux processus et publier les preuves de renouvellement et d’isolation du trousseau.

- Comparer la connectivité du constructeur SBX au profil SRT admis. Mesurer la destination depuis l’UID du client, avec un deuxième serveur effectivement en écoute comme témoin du refus, puis vérifier les règles avant le transfert et après la sortie.
